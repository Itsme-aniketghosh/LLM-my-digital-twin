## Project Card 1: Biomedical Link Prediction ⭐ FEATURED

```
ICON:       fa-dna or fa-project-diagram
LINKS:      https://github.com/Itsme-aniketghosh/biomedical-link-prediction

TITLE:      Biomedical Knowledge Graph Link Prediction

CONTEXT:    Course project for CS 5100 (Foundations of AI) at Northeastern
            under Professor Amir Tahmasebi

DESCRIPTION:
Comparative study of link prediction methods on the BioRED biomedical 
knowledge graph. Benchmarked 7 models and discovered that classical ML 
dramatically outperforms state-of-the-art knowledge graph embeddings 
on sparse biomedical data:

• Random Forest:  0.94 AUC (WINNER)
• Gradient Boost: 0.93 AUC
• ComplEx:        0.71 AUC
• TransE:         0.61 AUC

Implemented multi-hop reasoning that traces paths through intermediate 
biological entities, providing human-readable explanations for every 
high-confidence prediction.

KEY INSIGHT:
"Simple beats complex on sparse graphs. Structural features like 
preferential attachment and PageRank capture fundamental patterns 
that embedding models struggle to learn with limited data."

TAGS:       Knowledge Graphs | PyTorch | scikit-learn | NetworkX | BioRED

METRICS:    7 models | 0.94 AUC | Explainable multi-hop reasoning
```
